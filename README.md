# Острів — MVP, етап 1: профіль гравця

Що вже працює: юзер відкриває Mini App у Telegram → бекенд автоматично створює
профіль (внутрішній ID, унікальний тег `Нікнейм#1234`, випадкова дефолтна
аватарка) → фронтенд показує картку профілю.

**Фронтенд і бекенд працюють на одному порту (8000)** — бекенд сам роздає
HTML/CSS/JS фронтенду. Це означає, що потрібен лише **один** ngrok-тунель,
а не два.

## Структура проєкту

```
island-mvp/
├── backend/
│   ├── main.py           # FastAPI застосунок: API + роздача фронтенду
│   ├── auth.py            # перевірка справжності даних від Telegram
│   ├── database.py        # підключення до SQLite (async)
│   ├── models.py           # модель User
│   ├── schemas.py          # Pydantic-схеми відповідей
│   ├── requirements.txt
│   ├── .env.example
│   ├── run.sh              # скрипт швидкого запуску
│   └── static/avatars/     # 6 дефолтних аватарок (SVG)
└── frontend/
    ├── index.html
    ├── style.css
    └── app.js               # звертається до API за відносним шляхом (той самий порт)
```

## Крок 1. Створи бота в Telegram

1. Напиши [@BotFather](https://t.me/BotFather) в Telegram
2. Команда `/newbot`, дай назву і username (має закінчуватись на `bot`)
3. BotFather видасть токен виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   — збережи його, знадобиться далі

## Крок 2. Запусти бекенд (він же роздасть і фронтенд)

```bash
cd island-mvp/backend
chmod +x run.sh
./run.sh
```

Скрипт сам створить віртуальне середовище, встановить залежності і запустить
сервер на `http://localhost:8000`.

При першому запуску він скопіює `.env.example` в `.env` — **відкрий `.env` і
встав туди свій BOT_TOKEN** з Кроку 1, потім перезапусти `./run.sh`.

Перевір що все працює:
- `http://localhost:8000/api/health` — має повернути `{"status":"ok"}`
- `http://localhost:8000/` — має показати сторінку профілю (з помилкою про
  Telegram, це нормально — ти відкрив напряму в браузері, не через бота)

**Лишаєш цей термінал відкритим.**

## Крок 3. Відкрий один тунель ngrok

В новому терміналі:

```bash
ngrok http 8000
```

Ngrok видасть посилання типу `https://abcd1234.ngrok-free.app` — це і є
адреса твого застосунку, більше нічого прокидати не треба.

**Якщо ngrok видає помилку `ERR_NGROK_334` ("endpoint already online")** —
значить в тебе вже десь запущений інший ngrok-тунель (наприклад забутий
термінал). Перевір і закрий старі:
```bash
pkill ngrok
```
і запусти `ngrok http 8000` знову.

## Крок 4. Прив'яжи Mini App до бота

1. Напиши [@BotFather](https://t.me/BotFather) → `/mybots` → обери свого бота
2. `Bot Settings` → `Menu Button` → `Configure Menu Button`
3. Встав ngrok-посилання з Кроку 3
4. Дай кнопці назву, наприклад "Відкрити острів 🏝️"

## Крок 5. Перевір

1. Відкрий бота в Telegram на телефоні
2. Натисни кнопку меню "Відкрити острів"
3. Має з'явитись екран завантаження → потім картка профілю з аватаркою,
   нікнеймом і тегом

⚠️ Кожен перезапуск `ngrok http 8000` дає нове посилання — після перезапуску
треба заново оновити Menu Button URL в BotFather (Крок 4). API_BASE_URL в
`app.js` міняти вже не треба, бо він відносний.

## Наступні кроки (не входять у цей етап)

- Grid острова і розміщення об'єктів
- Прив'язка фото/тексту-спогаду до об'єкта
- WebSocket для live-оновлень, коли на острові хтось інший
- Деплой бекенду на Render + PostgreSQL замість SQLite + ngrok (стала адреса,
  не треба щоразу оновлювати посилання)
- Заміна аватарок на кастомні (зараз 6 простих SVG-заглушок у
  `backend/static/avatars/`)

## Типові проблеми

- **"BOT_TOKEN не налаштовано"** — не заповнив `.env` або не перезапустив сервер
- **"Недійсні дані Telegram (init_data)"** — фронтенд відкрито не через
  Telegram (напряму в браузері), або BOT_TOKEN в `.env` не той, що видав
  BotFather для цього бота
- **`ERR_NGROK_334` при запуску ngrok** — вже є запущений тунель, зроби
  `pkill ngrok` і спробуй знову
- **Помилка збірки `pydantic-core` при `./run.sh`** — стара версія pip
  намагається компілювати з Rust. Онови `requirements.txt` (версії без
  жорсткої фіксації `==`, з `>=`) і видали папку `venv` перед повторним
  запуском
